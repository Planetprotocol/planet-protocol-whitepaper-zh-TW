# 查核架構

Planet Protocol 採用**五層查核架構**,以彌合鏈上智慧合約與鏈下農業營運之間的信任落差。每一層處理不同面向的風險,並在批次生命週期的不同階段運作。

---

## 信任問題

僅處理純數位資產的 DeFi 協議,可以完全在鏈上驗證狀態。實體資產協議面臨的挑戰則本質不同:底層資產存在於實體世界,其狀態無法由智慧合約原生讀取。

Planet Protocol 必須回答區塊鏈本身無法回答的問題:

- 這座農場真的存在嗎?
- 這位融資方是否確為其所聲稱的身分?
- 作物是否真的已經種下?
- 收成是否確實正在進行?
- 融資方最終是否會還款?

五層查核架構的設計目的,就是針對這些面向逐步建立更高的信心水準。

---

## 五個層級

### 第一層 — 融資方身分查核

**時機:** 批次建立之前
**內容:** 查核融資方的法律身分、商業登記與營運歷史

本層確立融資方是真實、可識別且具備可查證紀錄的實體。Planet Labs 執行:

- 比對當地登記機關進行商業登記查核
- 主要負責人的身分查核
- 營運歷史評估(經營年數、過往融資紀錄)
- 銀行帳戶與收付管道查核
- 在可行情況下向供應鏈夥伴進行徵信查詢

**產出:** 融資方獲准或遭拒建立批次。

### 第二層 — 資產與營運查核

**時機:** 批次架構設計期間,部署之前
**內容:** 查核底層農業營運及其經濟可行性

本層確認融資申請確實有真實且經濟上可行的農業營運作為後盾。評估範圍包括:

- 實地場址查核(實地查驗或衛星影像確認)
- 作物種類與生長季節驗證
- 該區域與該作物的歷史單位產量資料
- 供應鏈收購安排(買方合約或市場通路確認)
- 財務模型審閱(成本結構、預期營收、毛利分析)

**產出:** 批次參數定案並獲准部署。

### 第三層 — 里程碑證明查核

**時機:** 批次生命週期中的每個里程碑
**內容:** 在撥款前即時查核里程碑條件確已達成

這是操作上最關鍵的一層。在每個里程碑,融資方須提交該里程碑已達成的證明。證明類型包括:

- **Milestone 1(種植):** 種植確認照片、種子與農業投入品採購憑證、農藝師報告
- **Milestone 2(生長):** 生長期查驗照片、衛星影像更新、農業投入品施用紀錄
- **Milestone 3(收成):** 收成文件、倉單、買方交貨確認、銷售發票

Planet Labs 透過下列方式綜合查核這些證明:
- 當地田野專員直接查驗
- 第三方農藝師審閱
- 衛星與遙測資料交叉比對
- 文件真偽查核

**產出:** 里程碑於鏈上確認,觸發 EscrowVault 撥款。

### 第四層 — 財務對帳

**時機:** 收成後,收益分配之前
**內容:** 查核融資方的回款是否符合約定條件

本層確保財務結算精確且完整:

- 確認融資方存入的回款金額與約定相符
- 將實際銷售所得與預估回款進行對帳
- 開放領取前確認 ClaimVault 餘額

本階段不計算亦不扣除任何平台費用。3% 鑄造費僅於上游的初級銷售階段收取一次,結算階段不再收取任何費用——參見[商業模式](../Economics/Business-Model.md)。

**產出:** ClaimVault 完成注資,代幣持有人可開始領取。

### 第五層 — 持續監控與預言機整合

**時機:** 貫穿整個批次生命週期
**內容:** 持續性的風險監控與異常偵測

本層在離散的里程碑查核點之外,提供持續性的監督:

- **氣候與天候監控** — 追蹤可能影響作物表現的惡劣天候、乾旱、洪澇或蟲害爆發
- **市場價格監控** — 追蹤與該批次作物相關的大宗商品價格
- **融資方行為監控** — 異常活動模式、聯繫中斷或其他早期預警訊號
- **預言機整合** — 在可行情況下,整合第三方資料預言機以取得自動化資料饋送(天候資料、大宗商品價格、衛星指數)

**產出:** 向 Planet Labs 營運人員發出風險警示與早期介入訊號。

---

## 查核不等於保證

必須說明的是,查核可降低風險,但無法消除風險。Planet Protocol 的查核架構提供:

- 對融資方與營運合法性的**合理確信**
- 對里程碑進度的**證據性確認**
- 對新生風險的**持續監控**

但它**不**提供:

- 融資方還款的保證
- 針對作物歉收、天然災害或市場崩跌的保險
- 鏈下協議的法律強制執行(此部分透過另行簽署的法律架構處理)

殘餘風險的完整討論請參閱[風險揭露](../Risks.md);關於提供額外損失緩衝的 $PNT 質押機制,請參閱[融資方擔保機制](../Economics/Originator-Security.md)。

## 現況與發展規劃

| 層級 | 目前實作方式 | 規劃中的強化 |
|---|---|---|
| 第一層 — 身分 | Planet Labs 人工查核 | 整合第三方 KYC/AML 服務商 |
| 第二層 — 資產 | 人工查驗加文件審閱 | 整合衛星影像 API |
| 第三層 — 里程碑 | 人工證明審閱 | 自動化證明評分;去中心化查核網路 |
| 第四層 — 財務 | 人工對帳 | 自動化 USDC 金流追蹤 |
| 第五層 — 監控 | 人工監控 | 預言機自動警示;IoT 感測器整合 |

Planet Protocol 的查核架構規劃隨時間逐步走向自動化與去中心化,同時在關鍵決策節點維持人工監督。
