# 商業模式

Planet Protocol 透過單一且透明的費用機制產生營收:**鑄造費**。不存在任何隱藏收費、以代幣為手段的價值抽取,或依賴投機的營收來源。

---

## 鑄造費

鑄造費是向參與者於初級銷售中每一筆購買所收取的比例費用。它在購買當下自購買金額中扣除,直接轉入 Planet Labs 國庫錢包;餘額則在同一筆交易中轉入該批次的 EscrowVault。

| 參數 | 內容 |
|---|---|
| 費用類型 | 初級銷售中每筆購買金額的比例 |
| 費率 | 各批次於部署時設定,合約上限為 3%(`MAX_FEE_BPS = 300`) |
| 收取對象 | 參與者(自購買金額中扣除) |
| 收取時點 | 每一筆購買當下,於 PrimarySale 合約內,淨額進入 EscrowVault 之前 |
| 收款方 | Planet Labs 國庫錢包 |
| 批次日後失敗時 | 費用不予退還。退款僅涵蓋託管中的淨額 |

### 主要特性

**由參與者承擔:** 鑄造費自參與者的購買金額中扣除。參與者支付掛牌代幣價格,該費用減少的是這筆付款最終進入批次的額度,而非在價格之上額外加收。以 3% 費率購買 10,000 USDC 為例,300 USDC 進入國庫,9,700 USDC 進入 EscrowVault。

**於購買時收取,而非結算時:** 費用在與購買相同的交易中轉入國庫,不進入託管,不以批次達成募資目標為前提,也不以批次成功為前提。其對利益一致性與失敗批次退款的影響,請參閱[風險揭露](../Risks.md)。

**逐批次設定,上限 3%:** 費率於各批次部署時設定,該批次存續期間固定不變。智慧合約會拒絕任何高於 3% 的費率設定,個別批次亦可以較低費率部署。

**單向收取:** 該費用僅於購買時收取,持有、領取或銷毀階段皆不再收取。融資方不被收取任何費用——參見下方[Planet Protocol 不收取的費用](#planet-protocol-不收取的費用)。

**批次缺口為其後果:** 由於費用在資金進入託管之前即已扣除,一個以 3% 費率售出 100,000 USDC 代幣的批次,實際進入託管的是 97,000 USDC 而非 100,000 USDC。這是費用模型的結構性特徵,而非錯誤——完整機制與其對融資方設定融資需求的影響,請參閱[單位經濟](Unit-Economics.md#鑄造費與批次缺口)。

## 利益一致性

**與融資方的一致性:** 由於費用是在購買時向參與者收取,而非自里程碑撥款中扣除,融資方可取得進入 EscrowVault 的全部淨額,並在批次生命週期的任何後續階段都不再被扣除費用。這正呼應了 Planet Protocol 相對於非正規與多層中介農業信貸管道的定位——後者的成本往往在多個環節被反覆抽取。

**與參與者的一致性:** 各批次費率於部署時固定並於購買前揭露,PrimarySale 合約另提供 `getQuote()` 函式,可查詢任何購買數量對應的確切總額、費用與淨額。不存在浮動價差、隱藏收費或事後追溯調整。

**此費用結構未能做到的事:** 由於費用在購買時而非里程碑完成時收取,Planet Labs 在單一批次上的收入,早在任何里程碑獲得查核之前即已結清,且不以批次成功為前提。參見[費用結構與激勵時點風險](../Risks.md#費用結構與激勵時點風險)。

**不依賴代幣:** Planet Labs 的核心營收模式不依賴任何代幣的價格上漲或交易量。平台的可持續性建立在真實經濟活動之上——對初級銷售量收取的固定比例費用。

## Planet Protocol 不收取的費用

| 費用類型 | 狀態 |
|---|---|
| 融資方融資手續費 | 無——融資方於批次建立、里程碑撥款或還款階段皆不被收費 |
| 參與者退出費 | 無 |
| 代幣轉讓費 | 無 |
| 領取/銷毀費 | 無 |
| 收益績效費 | 無 |
| 融資方上架費 | 無 |

## 未來營收方向

隨著協議成熟,可能導入額外的營收來源。以下項目目前均未實作,並將經由治理審議與社群意見決定:

- **次級市場費用** — 待次級市場開放後,對 RWA 代幣的次級交易收取小額交易費
- **資料與分析服務** — 面向機構參與者的進階資料饋送或報告服務
- **查核即服務** — 將 Planet 的查核基礎設施提供予第三方 RWA 協議使用

任何新的費用機制都將事先公告,並反映於更新後的協議文件中。
